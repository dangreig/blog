## brain dump

A small GitHub Pages site for dgreig's writing and reading notes.

The live site is built from `index.html` with GitHub Pages configuration in `_config.yml`.

## Adding posts

1. Copy `post-template.md`
2. Save it in `_posts/` as `YYYY-MM-DD-title.md`
3. Update the `title`, `date`, and `summary`
4. Write the post in Markdown

GitHub Pages will build the post automatically and list it on the homepage archive.
