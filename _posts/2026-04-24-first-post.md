This is a starter post written in Markdown.

You can replace this with whatever you actually want to publish. The key difference now is that the writing lives here in `_posts`, while the homepage archive is generated automatically.

## How to use this

- Create a new file in `_posts`
- Name it `YYYY-MM-DD-title.md`
- Add the front matter block at the top
- Write the post in Markdown

When you push to GitHub Pages, Jekyll will build the post page and add it to the archive on the homepage.
